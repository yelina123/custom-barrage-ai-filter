# 自定义弹幕AI过滤器

一个运行在 Chrome / Edge 浏览器（其它浏览器未测试）中的 B 站弹幕过滤扩展，使用 **TypeSafe Jev** 按你自定义的规则分析弹幕，帮助屏蔽不想看到的内容（剧透、骂人、引战等均可）。

> 考虑到速度和成本问题，AI 只分析弹幕文字，不会读取视频内容，所以可能出现误判。

![插件面板](./assets/panel.png)

## 与原版的区别

- **支持自定义过滤内容**：可自行编辑“系统提示词”（过滤规则）和逐条弹幕的“判断问题”，想过滤什么就过滤什么；默认仍为剧透过滤。
- **命中弹幕替换为空格**：不再用“已过滤/已屏蔽”等占位文字挡画面，命中的弹幕直接变成一个空格，等同消失且不影响其他弹幕。

## 安装

1. 点击[下载最新版扩展 ZIP](https://github.com/yelina123/custom-barrage-ai-filter/releases/latest/download/custom-barrage-ai-filter.zip)。
2. 将 ZIP 解压到固定目录。
3. 打开扩展管理页：Chrome 在地址栏输入 `chrome://extensions/` 进入，Edge 在地址栏输入 `edge://extensions/` 进入。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压后包含 `manifest.json` 的目录。
5. 打开或刷新 B 站视频页，若出现机器人图标则安装成功。

![安装成功后的机器人图标](./assets/success.png)

安装后请保留该目录。更新扩展文件后，在扩展管理页点击“重新加载”，并刷新 B 站页面。

## 使用方法

1. 点击机器人图标，打开插件面板。
2. 进入设置，在 API 中填写 Base URL、Model 和 API Key，支持 Jev 官方 API 或 OpenRouter 等中转站。
3. 在“功能”中按需修改系统提示词和判断问题（不改则使用默认的剧透过滤规则），点击“测试”确认连接正常。
4. 返回主面板点击“开始分析”。测试和分析均会调用第三方 API，费用由服务商收取。
5. 分析完成后，根据观看需要调整屏蔽阈值。开启“自动”后，刷新或切换视频时会自动处理。

## 自定义过滤示例

- 过滤剧透（默认）：系统提示词描述什么是剧透，判断问题为“这条弹幕是否符合应当被过滤的条件？”。
- 过滤骂人弹幕：把系统提示词改为“过滤包含辱骂、人身攻击、脏话的弹幕”，判断问题改为“这条弹幕是否包含辱骂或脏话？”。
- 过滤引战/刷屏：在系统提示词中描述引战、地域攻击或无意义刷屏的特征即可。

## 功能

- 支持 B 站普通视频页和番剧播放页的弹幕分析和屏蔽。
- 支持手动分析和自动模式；自动模式下，分析期间会暂停视频，完成后恢复播放。
- 发送前对弹幕文本去重，减少重复分析；缓存上一次完整分析的视频结果，刷新同一视频可直接复用（修改提示词或问题后缓存自动失效，不会混用）。
- 支持自定义系统提示词、判断问题、单次请求弹幕数量、并发数、请求超时和命中后的替换文本。

## 从源码构建

需要 Node.js 20.19+（20.x）或 22.12+。

```sh
npm ci
npm run build
```

构建完成后，按照上面的安装步骤加载 `dist` 目录。

```sh
npm run typecheck  # 类型检查
npm test          # 自动化测试
```

Windows 下可运行 `npm run package:extension` 生成发布 ZIP 包，输出位于 `release` 目录。
